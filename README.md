# 🛒 Customer Shopping Behavior Analytics

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, product performance, discount usage, shipping preferences, subscription behavior, and spending trends.

The project follows an end-to-end data analytics workflow using Python for data cleaning and exploratory analysis, MySQL for database storage and SQL business analysis, and Power BI for interactive visualization.

---

## 🎯 Business Objective

The objective of this project is to transform raw customer shopping data into actionable business insights by analyzing:

* Customer purchasing behavior
* Product and category performance
* Customer spending patterns
* Discount and promotional usage
* Shipping preferences
* Subscription behavior
* Customer segmentation
* Review ratings

## 🐍 Python — Data Cleaning & EDA

Python and Pandas were used to prepare the dataset for analysis.

Key activities included:

* Data inspection
* Data cleaning
* Missing value handling
* Data type validation
* Column standardization
* Feature engineering
* Customer segmentation

The cleaned dataset was then loaded directly into MySQL for further analysis.

## 💡 Key Insights

* Young Adults generated the highest proportion of total sales, followed by Middle-Aged Adults.
* More than 2,500 repeat/loyal buyers with more than five prior purchases were identified as non-subscribers.
* Customers using Express Shipping had a higher average spend than Standard Shipping customers.
